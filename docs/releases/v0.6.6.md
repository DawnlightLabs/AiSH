# AiSH v0.6.6

AiSH v0.6.6 makes natural-language project launching reliable across common application stacks and improves the experience of running foreground development servers.

## Generic project launching

- Detects runnable targets from real project manifests, entrypoints, and task files instead of relying on model-generated launch commands.
- Supports Node.js, Rust, Python, Go, .NET, Java, PHP, Ruby, Flutter and Dart, Docker Compose, Swift, Deno, Make and Just, Elixir, Haskell, Zig, R, Lua, Perl, scripts, and static sites through typed host-side runner profiles.
- Selects declared tasks safely, validates relative entrypoints, and rejects unsafe task names or path traversal.
- Asks a concise clarification when multiple independent targets are available or when no trustworthy entrypoint can be found.
- Keeps project launches approval-gated and compiles commands independently of the local language model.

## Foreground process experience

- Shows the working directory and command before starting a project or development server.
- Warns when a process may continue running and explains that `Ctrl+C` stops it.
- Streams foreground stdout and stderr live instead of buffering all server output until exit.
- Preserves ordered setup-and-run plans, streaming the final foreground step after setup succeeds.

## Reliability and compatibility

- Keeps explicit script and file requests on the dedicated script-execution path instead of misrouting them as project launches.
- Uses platform-appropriate launch commands on Windows, Linux, and macOS.
- Preserves host-side risk classification and approval requirements for every compiled command.
- Expands the generated dynamic sandbox suite to 51 scenarios, including multi-language project fixtures, ambiguous targets, scripts, mutations, navigation, recovery, and routing.
