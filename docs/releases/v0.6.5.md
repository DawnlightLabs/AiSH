# AiSH v0.6.5

AiSH v0.6.5 hardens host-grounded execution for realistic project, filesystem, script, and terminal requests while preserving the semantic planner and approval model introduced in v0.6.4.

## Planning and recovery

- Adds a deterministic host-compiled fallback after bounded model repair fails, without executing unvalidated model prose.
- Grounds current-project run requests, standard observations, directory metrics, named searches, navigation, and filesystem actions against the live working directory.
- Preserves follow-up intent using bounded recent-session context.
- Keeps failed-command diagnosis non-recursive and separates explanations from corrected commands.

## Filesystem and project actions

- Adds typed create, write, append, delete, rename, move, and copy plans with host-side path resolution.
- Resolves redirected Windows known folders and existing filesystem entries before rendering commands.
- Preserves exact names, spaces, mixed case, quoted paths, and Unicode without inventing separators or alternate spellings.
- Verifies state-changing filesystem results and keeps mutations approval-gated.

## Scripts and terminal behavior

- Resolves existing local PowerShell, Python, JavaScript, and shell scripts generically by name and extension.
- Selects platform-appropriate interpreters and quotes script paths and arguments safely.
- Supports bounded synchronous multi-step objectives that stop on failure.
- Reports successful commands with no output and failed commands with no output instead of returning a blank prompt.
- Prevents detached or persistent terminal launches in host-compiled task execution.

## Safety

- All generated and host-compiled commands continue through host risk classification.
- State-changing commands remain approval-gated; deletion remains high risk.
- Read-only commands cannot silently substitute for requested mutations.
- Existing-target operations validate filesystem entries before command generation.

## Upgrade

Inside AiSH, run:

```text
/update
```

Or from PowerShell, Command Prompt, bash, or zsh:

```text
aish --update
```

Restart AiSH after the updater finishes.
